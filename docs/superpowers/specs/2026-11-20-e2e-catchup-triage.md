4. **`ui-pattern:list-default-scope`** — PR list opens on "My pending" (empty for the role), so `openRecordFromRow` finds no rows; specs need to switch to All Documents first. Also possibly empty because of data; confirm in Task 1.
5. **Auth outage page** replaces the inline server-unavailable message (`TC-LOGIN-010040`, FE `fb163b1c`, `793b4c41`, `55da7146`) — intentional, update test.
